Aar Desktop for Linux (early preview)
=====================================

English
-------
1. Unpack this archive where the program should stay (e.g. ~/Programs).
2. Run ./install.sh – Aar appears in the application menu (command: aar-desktop).
   It needs WebKitGTK 4.1; install.sh tells you the package if it is missing.
3. Start Aar. The setup assistant installs a local language model (Ollama,
   into ~/.local) or connects a cloud provider.

Not on Linux yet: operating other programs (clicking, typing, Paint).
Aar works with files, commands and – with the web add-ons – web pages.
Keyboard shortcut on Wayland: add a shortcut for the command "aar-desktop"
in the system settings; starting it again opens and closes Aar.
Remove: ./uninstall.sh, then delete this folder.

Deutsch
-------
1. Archiv dort entpacken, wo das Programm bleiben soll (z. B. ~/Programme).
2. ./install.sh ausführen – Aar steht danach im Anwendungsmenü (Befehl: aar-desktop).
   Benötigt WebKitGTK 4.1; fehlt es, nennt install.sh das Paket.
3. Aar starten. Der Einrichtungsassistent installiert ein lokales Sprachmodell
   (Ollama, nach ~/.local) oder verbindet einen Cloud-Anbieter.

Unter Linux noch nicht dabei: andere Programme bedienen (klicken, tippen, Paint).
Aar arbeitet mit Dateien, Befehlen und – mit den Web-Add-ons – mit Webseiten.
Tastenkürzel unter Wayland: in den Systemeinstellungen ein Kürzel für den
Befehl „aar-desktop“ anlegen; ein zweiter Start öffnet und schließt Aar.
Entfernen: ./uninstall.sh, danach diesen Ordner löschen.
